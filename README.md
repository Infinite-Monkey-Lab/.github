# Infinite Monkey Lab · 组织规范

此仓库维护组织首页、项目目录和组织级默认社区文件。公开仓库如未提供自己的对应文件，可使用这里的默认规范；项目仓库已有专门规则时，以项目自身内容和项目实际许可证为准。

## 项目导航

组织首页设有六个分类根仓库，各分类 README 维护索引；源码、问题跟踪、发布和项目维护在独立项目仓库中进行。查看[项目地图](PROJECT_CATALOG.md)或[组织首页](https://github.com/Infinite-Monkey-Lab)。

## 基本约定

- 每个项目只选择一个主要分类；目录条目链接到项目独立主页。
- 项目页说明目标、当前状态、维护者、许可证、快速开始和协作方式；不确定的信息标为待确认。
- 研究项目补充来源、数据与模型授权、环境、配置、指标、结果差异和限制。
- 不为所有项目指定统一代码许可证。代码、数据、模型和素材分别核对授权。
- Issue 用于具体、可跟进的任务；尚在探索的问题和开放讨论优先使用 Discussions。
