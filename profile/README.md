# 无限猴子实验室 · Infinite Monkey Lab 🐒⌨️

> **无限猴子开源社区 | 学生开源社区**
> 让思维的闪光变成作品，让愿意投入的人找到伙伴，
> 给还没长成的想法一点时间，也给认真动手的人一个可以共同创造的天地。

「无限猴子定理」说：一只猴子在打字机上随机敲击无限久，终会敲出莎士比亚全集。
我们相信：给一个想法足够的时间、伙伴与练习，学生也能敲出了不起的作品。

## 🧪 我们在做什么

- 🌱 **从 0 到 1 的开源实践** —— 想法 → 提案 → 组队 → 迭代 → 发布，完整走一遍开源协作流程
- 🤝 **伙伴匹配** —— 让愿意投入的人找到同路人，一个人走不动的路，一起走
- 📚 **在实践中成长** —— 代码评审、分支管理、CI/CD、开源文化，动手学，不纸上谈兵

## 🚀 如何参与

1. 到感兴趣的仓库 Issue 区认领任务（找 `good first issue` / `help wanted` 标签）
2. 或开一个新 Issue，写下你的想法——**还没长成的想法也欢迎**
3. Fork → 修改 → 提交 Pull Request，维护者会尽快 review

> 新手完全不用担心：每个仓库的 issue 区都可以提问，犯错是这里最不值钱的东西。
