## 找到你的第一步

参与免费，不限学生身份、技术基础或地区，也无需先成为组织成员。

| 你想做什么 | 可以从哪里开始 |
| :--- | :--- |
| 使用工具、反馈体验 | 到对应项目报告一个问题，附上复现步骤 |
| 写文档、做设计或翻译 | 改进一段安装说明、一个示例或一张图 |
| 写代码、做实验 | 选择一个 Issue，明确范围，提交附验证方法的 PR |
| 找伙伴、讨论新想法 | 到 [Discussions](https://github.com/Infinite-Monkey-Lab/infinite-monkey-lab/discussions) 分享问题与已有尝试 |

小改进可以直接提交 PR；较大任务先讨论目标、交付与需要的帮助。完整流程见[贡献指南](https://github.com/Infinite-Monkey-Lab/infinite-monkey-lab/blob/main/CONTRIBUTING.md)。

## 当前共创：校园知识助手

[Campus Knowledge Assistant](https://github.com/Infinite-Monkey-Lab/infinite-monkey-lab/blob/main/projects/campus-knowledge-assistant/README.md) 是首期共创提案：围绕有权使用的小规模资料，提供带来源引用的问答，并在资料不足时明确拒答。

**该共创项目仍处于提案阶段，尚无可运行代码。** 社区启动与协作机制也在筹备中；上方独立项目的状态以各自仓库为准。欢迎参与样例资料、检索评测、接口、界面与测试，具体范围见[项目提案](https://github.com/Infinite-Monkey-Lab/infinite-monkey-lab/blob/main/projects/campus-knowledge-assistant/README.md)与[路线图](https://github.com/Infinite-Monkey-Lab/infinite-monkey-lab/blob/main/ROADMAP.md)。

## 为什么叫「无限猴子」

**每个人都是猴子。** 名字借用了无限猴子在打字机前不断尝试的思想实验。我们也从有限的知识出发，借助 AI 提问、动手、验证和修改，让一个还不成熟的想法逐渐成为作品。

公开一次尝试、一份失败记录或一点改进，就给下一位参与者留下了起点。**不断尝试，共同创造。 · Keep Trying. Create Together.**

## 我们如何协作

- **公开过程**：用 Issue 跟进任务，用 PR 交付改进，留下决策、验证与复盘。
- **认真验证**：说明环境、来源和限制，区分已完成与计划；AI 辅助的内容也由贡献者理解并核验。
- **尊重贡献**：友善反馈，保留署名；文档、设计、测试与研究同样值得认可。
- **说明许可**：各项目使用自己的许可证，第三方代码、数据、模型与素材分别核对授权。

更多说明：[开放成果规则](https://github.com/Infinite-Monkey-Lab/infinite-monkey-lab/blob/main/docs/openness.md) · [社区规范](https://github.com/Infinite-Monkey-Lab/infinite-monkey-lab/blob/main/CODE_OF_CONDUCT.md) · [治理章程](https://github.com/Infinite-Monkey-Lab/infinite-monkey-lab/blob/main/GOVERNANCE.md) · [安全报告](https://github.com/Infinite-Monkey-Lab/.github/blob/main/SECURITY.md)。不公开密钥、个人隐私或无权分发的材料；漏洞请通过安全规范中的私密渠道报告。
