## 🐒 为什么叫「无限猴子」

名字借用了「无限猴子」的思想实验：在理想化的无限随机尝试中，猴子在打字机上也可能敲出莎士比亚的《哈姆雷特》。

面对 AI 展现出的能力，我们愿意把自己比作坐在打字机前的猴子：知识有限，未必一开始就知道怎样创造，但仍然可以开始尝试。借助 AI 提问、动手、观察结果，再验证、修改和重来，普通人也有机会做出原本做不出的东西。

给一个想法足够的时间、伙伴与练习，学生也能敲出了不起的作品。每个人的一次小尝试、一份失败记录、一点改进，都可以成为下一位参与者的起点。我们把过程与成果开放，让尝试能够被看见、被检验、被接续。

## 🧪 我们在做什么

- 🌱 **从 0 到 1 的开源实践**：想法 → 提案 → 组队 → 迭代 → 发布，完整走一遍协作流程，把思维的闪光变成可运行、可检验的作品。
- 🤝 **找到一起动手的伙伴**：公开兴趣、任务与协作需求，让愿意投入的人找到同路人。还没长成的想法也欢迎，先从一次小范围合作开始。
- 📚 **在实践中成长**：通过文档、代码、测试和评审，学习 Git、分支管理、工程交付与开源文化；在项目需要时补充 CI/CD 和部署实践。
- 🔬 **连接学习、研究与工程**：用同一个项目学习 AI、复现方法、设计实验、完善应用，也把真实贡献整理成作品集。

你可以从 [新成员入门](https://github.com/Infinite-Monkey-Lab/infinite-monkey-lab/blob/main/docs/getting-started.md) 开始，再按兴趣选择 [成长路径](https://github.com/Infinite-Monkey-Lab/infinite-monkey-lab/blob/main/docs/learning-path.md)、[科研实践](https://github.com/Infinite-Monkey-Lab/infinite-monkey-lab/blob/main/docs/research-track.md) 或 [工程与就业方向](https://github.com/Infinite-Monkey-Lab/infinite-monkey-lab/blob/main/docs/career-track.md)。方向可以交叉，无需按固定等级或学期推进。

## 🚀 如何参与

1. 到 [社区启动仓库](https://github.com/Infinite-Monkey-Lab/infinite-monkey-lab) 了解项目，阅读 [贡献指南](https://github.com/Infinite-Monkey-Lab/infinite-monkey-lab/blob/main/CONTRIBUTING.md)。
2. 在 [Issues](https://github.com/Infinite-Monkey-Lab/infinite-monkey-lab/issues) 找合适任务，可优先查看 `good first issue` / `help wanted`；较大任务先说明计划、交付和需要的帮助。
3. 没有合适任务，就 [提出一个想法](https://github.com/Infinite-Monkey-Lab/infinite-monkey-lab/issues/new?template=task.yml)，或到 [Discussions](https://github.com/Infinite-Monkey-Lab/infinite-monkey-lab/discussions) 提问、寻找伙伴、分享学习与失败记录。
4. Fork → 创建分支 → 完成一个小而完整的改进 → 提交 PR，附验证方法并回应评审。维护者按任务标准和实际精力安排反馈。

## 🛠️ 从一个项目开始

首期共创提案是 [Campus Knowledge Assistant · 校园知识助手](https://github.com/Infinite-Monkey-Lab/infinite-monkey-lab/blob/main/projects/campus-knowledge-assistant/README.md)：围绕有权使用的小规模资料，实现检索、问答、来源引用与资料不足时的拒答。

学习成员可以整理原创样例、验证入门流程；研究成员可以设计检索与引用评测；工程成员可以实现接口、界面、测试和运行说明。大家共享同一个问题定义与验收标准。

**当前仍处于筹备阶段，启动仓库主要是社区手册、模板和项目提案，尚无可运行的应用实现。** 后续候选包括论文复现与 Agent 共创，具体状态见 [项目目录](https://github.com/Infinite-Monkey-Lab/infinite-monkey-lab/blob/main/projects/README.md) 和 [路线图](https://github.com/Infinite-Monkey-Lab/infinite-monkey-lab/blob/main/ROADMAP.md)。

## 🌏 开源所有，人人参与

- **成果开放**：启动仓库原创内容沿用 [MIT License](https://github.com/Infinite-Monkey-Lab/infinite-monkey-lab/blob/main/LICENSE)；各项目明确自己的许可，第三方代码、数据、模型与素材保留各自授权。
- **过程开放**：需求、提案、任务状态、重要决策与复盘公开记录，让后来者可以接续；失败实验也有价值。
- **可复现优先**：提供环境、配置、来源、运行步骤和结果限制，区分已完成、计划与尚未验证的推测。
- **尊重贡献**：保留原作者署名，认可文档、测试、研究与评审；允许 AI 辅助，提交者理解并验证关键内容。

全部开源适用于我们有权发布的成果，不包含密钥、个人隐私、保密信息或无权再分发的材料。详见 [开放成果规则](https://github.com/Infinite-Monkey-Lab/infinite-monkey-lab/blob/main/docs/openness.md)。

## About us

Infinite Monkey Lab is a student-rooted open-source community open to everyone. We help people turn early ideas into shared projects through AI-assisted experimentation, hands-on learning and public collaboration.

Our name draws on the infinite monkey thought experiment. We see ourselves as curious beginners with powerful AI tools: by trying, checking, learning and sharing, anyone can contribute something worth building on. **Keep Trying. Create Together.**

The community is in preparation; the first campus knowledge assistant is still a proposal. Documentation, design, code, tests, reproducible experiments and reviews are all welcome. Chinese is our primary collaboration language, and English contributions are welcome too.
